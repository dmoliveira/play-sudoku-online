🌱 Quick start

Three ways to settle in fast

  • Read each cage as a tiny set: a 2-cell cage must use 1 and 2, a 5-cell cage must use 1 through 5.
  • Use Notes when a cage has several legal candidates, then switch back to values once touching-neighbor pressure narrows it.
  • Try Daily for a shared board or Challenge when you want fewer visible assists.
Basic walkthrough ↗ Back to board ↑

How Suguru differs

  • Each cage uses 1 up to its size. Small cages resolve fast; larger cages carry the main logic.
  • Matching digits cannot touch horizontally, vertically, or diagonally.
  • Daily keeps one deterministic board per date and level.
  • Challenge lowers assist feedback so you rely more on cage reading and neighbor pressure.
  • See a basic Suguru walkthrough ↗ if you want an example of neighbor-elimination logic.
